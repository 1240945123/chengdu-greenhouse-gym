## 1. 实验目的

1. **验证模型修复**：在前序修复（冠层过热 / 外遮阳透光 / 保温幕长波反射）后的物理模型上，
   重新训练 RL 控制器，确认修复未破坏温控与产量；
2. **优化控制策略**：针对环境轨迹图暴露的两个问题（湿度超标、白天开保温幕挡光），
   迭代优化奖励函数与状态表示；
3. **横向对比**：在同一天然孪生、同一 102 天生长季、同一评价口径下，
   对比 **PPO / SAC / 规则控制 / 固定基准** 四类控制器的温室状态、控制行为与性能。

## 3. 环境配置（统一口径）

```python
ENV_KW = dict(
    episode_days=102, start_day_index=0, crop_start="seedling",
    disable_supplements=True,
    cooling_weight=0.5, humidity_weight=2.0,
    cooling_mode="overheat", obs_include_outdoor=True,   # obs = 8 维含室外温度
    screen_shade_weight=0.5,                              # 白天顶保温挡光惩罚
)
```

| 参数 | 值 | 说明 |
|---|---|---|
| `episode_days` | 102（评估）/ 40（训练）| 4/1 定植 → 7/12 清棚 |
| `crop_start` | seedling | 幼苗起点，发育积温从 0 起算 |
| `disable_supplements` | True | 春夏茬禁用补光/CO₂ |
| `obs` | 8 维 | 室内温/湿/CO₂/冠层温/时间/果实/积温/**室外温** |

### 3.1 奖励函数

```
reward = 产量项 − 温度惩罚 − 湿度惩罚 − 能耗 + 降温奖励 − 挡光惩罚

产量项   = Δ果实鲜重[kg/m²] × 100
温度惩罚 = dist(T, 白天[20,28]/夜间[16,24]) / 10
湿度惩罚 = 2.0 × dist(RH,[60,85]) / 40
能耗     = 0.2 × (0.15风机 + 0.10水泵 + 0.05遮阳 + 0.20补光 + 0.15保温 + 0.05顶窗)
降温奖励 = 0.5 × max(0, T − 舒适上限) / 10        ← overheat 模式
挡光惩罚 = 0.5 × is_day × u[2] × 1(T ≥ 20°C)      ← 分温度惩罚
```

## 7. 结论

1. **PPO v6 综合最优**：舒适率 52.5%、果实 7.3 kg/m²、最高温 33.6°C 三项均第一，
   5/6/7 月舒适率全面领先。**相对人工（果实 3.1、舒适率 33.7%）为 2.35 倍产量、1.56 倍舒适率**。
2. **分温度挡光惩罚是关键优化**：一刀切惩罚会把 4 月舒适率打到 41.1%；
   改为「温度≥20°C 才罚」后，4 月恢复到 52.2%，同时果实回升到 7.28——
   **实现了「冷时保温、暖时拉起顶保温」的物理正确策略**。
3. **规则控制表现出乎意料地好**（舒适率 48.8%、果实 6.9、最高温 33.2），
   说明这座温室的温度分层规则本身有效；但 PPO 在果实与舒适率上仍稳定超过它，且无需人工调阈值。
4. **SAC 的短板是"饱和式控制"**：顶窗/水泵全开 → 湿度失控（6-7 月 >85%），
   舒适率仅 35.9%；其产量（6.6）尚可，但温控不稳。
5. **最优训练步数 = 60 万**：reward 曲线斜率趋 0 即甜点；加长到 120 万步因策略漂移果实反降 21%。

## 8. 备注与边界（诚实声明）

| 类别 | 说明 |
|---|---|
| **仿真边界** | 所有结果为数字孪生仿真，**未在真实温室部署验证** |
| **7 月物理上限** | 室外最高 37.5°C + 无制冷设备，7 月舒适率（PPO 18.8%）属物理约束，非算法问题 |
| **作物标定边界** | 作物实测仅覆盖 3/30–5/19，6-7 月无实测对照 |
| **密度假设** | 换算用 2.71 株/m²（管理文件参考值），需现场确认 |
| **保温链** | 修复后顶/四周保温 12h 增益 +0.77/+0.34°C；四周侧面长波为简化处理 |
| **动作位** | 补光/CO₂ 位在春夏茬恒 0（设计选择，非缺陷）|
| **可复现性** | 全部脚本已入库，见 `experiments/controllers/glass_rl/`；绘图流程见 `docs/notes/10-绘图工作流.md` |

## 四、本次核心问题

> **在「性能优化边际收益已耗尽」与「论文是刚性交付」的双重约束下，是否应当停止算法调参，把资源转向实验收口与论文写作？**

三个子问题需一并敲定：

1. **算法矩阵要不要补全？**（补 = 完整性，成本 = 后台 5-8h；不补 = 控制章只有 5 策略核心对比）
2. **论文主线结论定什么？**（A. RL 性价比论 / B. 模型可信性论 / C. 二者并重）
3. **性能优化是否封板？**（停止 PPO/SAC 变体实验）

---

## 五、决策结论与理由依据

### 决策 1：主线转向「实验收口 + 论文写作」✅

**理由**：
- **边际收益证据**：`comfort_bonus` 三轮（0.3/0.6）+ `smooth_pen` 两轮，**均未突破 52% 舒适率上限**；
  PPO v8 甚至以舒适率 −2.6 pp 换取产量 +0.78。**奖励塑形空间已耗尽**。
- **能力瓶颈已定位**：RL 落后 MPC 的 14.9 pp 来自**"逐步精细调节"能力**（MPC 有模型前瞻），
  这需要架构级改动（残差/蒸馏/频率），不是调参能解决，且 MPC 基线训练成本 10h 不可行。
- **现有结论已够强**：3 个模型缺陷诊断（方法学）+ 8.2% 作物标定 + 5 维 8 策略评估 +
  成本-性能权衡量化 —— **足以支撑一篇硕士论文的核心贡献**。
- **时间约束**：研三在读，论文还需写作 → 修改 → 送审 → 答辩多轮，**动手写是最迟不能晚的事**；
  且当前并行着秋招/公考，算力与精力都应留给刚性交付。

### 决策 2：算法矩阵「补，但最小化」✅

**范围**：统一重跑 7 个 RL 算法（a2c/dqn/sac/ddpg/td3/trpo/recppo）+ 多智能体；
**方式**：后台串行，独立进程防连锁崩溃（脚本与 `CurveCallback` bug 已修复）；
**不做**：不重跑 PPO（已有 v6/v8 两个标定后最优版）。

**理由**：算法矩阵是"benchmark 类论文"的**评审刚性要求**（"为什么没有 DDPG/TD3？"）；
成本可控（后台跑、不占人力、不阻塞写作）；但**不追求把每个算法调到最优**——
只要在同一协议下给出公平对比即可，避免陷入"逐个调参"的时间黑洞。

### 决策 3：论文主线结论定为「C. 二者并重」，落脚「RL 性价比」✅

**章节主线**：
```
模型可信性（3 个缺陷诊断 + 双 RMSE 校验）
    ↓
作物标定（郫都实测 8.2%）
    ↓
控制 benchmark（8 策略 × 5 维）
    ↓
核心论点：RL 以 MPC 1/83 的推理成本达其 74% 性能 + 100% 安全
```

**理由**：模型可信性是**方法学贡献**（区别于纯调参论文），RL 性价比是**应用贡献**（可落地）；
两者形成"可信孪生 → 可信控制"的闭环，逻辑自洽且不易被质疑。

### 决策 4：性能优化封板（本轮）✅

停止 PPO/SAC 变体实验。**切换条件**：若论文写作中发现某结论缺少实验支撑，**单点补实验**，
不重启大矩阵、不做超参搜索。

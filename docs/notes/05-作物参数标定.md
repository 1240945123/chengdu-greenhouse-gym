# 郫都作物参数标定（对齐 2026 郫都基地实测生长曲线）

> 日期：2026-09-10
> 关联：完整生长季 → 作物参数精标定（方案 A 的最终落地）

## 1. 标定数据来源

`E:\school\final paper\玻璃温室信息\2026郫都基地番茄测量数据.xlsx`（郫都基地 GH63，同棚）：
- **郫都1**：生物量鲜/干重（根/茎/叶/果）+ 三穗产量 + 甜度（12 株次）
- **郫都2**：株高/茎粗/茎节数/花序/果穗（12 株次）
- 3 个取样时间点：**2026-03-30、04-27、05-19**（每点 3 株）

种植密度参考 `番茄生长模型/management.csv`：**2.71 株/m²**。

## 2. 标定方法

1. **换算**：实测 g/株 → mg/m²（×1000×2.71），与仿真 cStem/cLeaf/cFruit（mg CH2O/m²）对齐。
2. **时间对齐**：仿真 seedling 起点（茎 7323 mg/m²≈2.7 g/株）≈ 实测 3/30（茎 2.15 g/株），故仿真 day0=3/30、day28=4/27、day50=5/19。
3. **参数敏感性 → 组合**：单参数扫描定位有效杠杆，再组合逼近目标。

## 5. 关键发现

1. **光合总量是瓶颈**（标定前低 2.3 倍）：有效杠杆是透光率 + 量子效率 + 降低维持呼吸，而非分配率。
2. **分配率是"零和"**：光合不足时单独调 rgStem/rgFruit 是反效果（抢叶→叶少→光合更少）。光合提升后分配调整才有效。
3. **canopy_frac 是过度约束**：冠层过热 bug 修复后，它反而压制了结果期果实，应去掉。
4. **标定后全季果实 ~3.4 kg/m² 鲜重**（固定物理控制），比标定前（RL 2.036）更贴合真实，印证此前"绝对产量偏保守"的判断。

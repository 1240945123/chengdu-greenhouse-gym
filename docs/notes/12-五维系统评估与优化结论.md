## 2. 逐维度分析

### 2.1 性能（舒适率 / 果实）
- **MPC 舒适率 67.4% 一骑绝尘**（比最佳 RL 高 14.9 pp），因它每步用真模型做候选搜索，直接优化舒适目标。
- **RL 内部分化**：PPO v6（52.5）> 残差PPO（50.9）> PPO v8（49.9）> SAC（36）。
- **产量最优是 PPO v8（8.06）**，牺牲 2.6 pp 舒适率换来 +0.78 kg/m²（vs v6）——**舒适与产量存在 Pareto 权衡**。

### 2.2 成功率
- 定义① 无过热日率（日最高温 ≤35°C，避免热害）：除人工（80.4%）与 SAC v3（90.2%）外，全部 100%。
- 定义② 舒适达标日率（日舒适 ≥50%）：**MPC 78.4% ≫ PPO 57.8% > 规则 52.0% > 残差 50.0% > SAC 31-33% > 人工 19.6%**。
- **结论**：RL 已能完全规避热害（安全性达 MPC 水平），但在"把每一天都控好"上仍落后 MPC ~20 pp。

### 2.3 稳定性
- 日均温标准差（日间波动）：**MPC 2.03 最低** < 规则 2.34 < PPO v8 2.81 < 残差 2.92 < PPO v6 2.94 < SAC v3 3.24 < SAC v4 3.48 < 人工 3.65。
- 日内波动：PPO v8 最小（1.82），SAC v3 最大（2.76）。
- 最高温极值：MPC 31.9 < PPO v8 32.6 < 规则/残差 33.2 < PPO v6 33.6 < SAC v4 34.8 < 人工 40.8 < **SAC v3 41.9**。
- **结论**：MPC 最稳；SAC 系列最不稳（其"饱和式控制"导致温度大幅摆动）；人工最不稳定。

### 2.4 样本效率
- 收敛速度（达最终收益 80% 的步数）：SAC v3 **122k 最快** < PPO v8 184k < PPO v6 221k < 残差 262k。
- 训练耗时：**残差 PPO 18 min 最短** < PPO v6 40 < PPO v8 50 < SAC 139。
- **结论**：**"学得快"≠"学得好"**——SAC 最快收敛却终值最差；PPO 用 1.5-2 倍时间换来高 16 pp 的舒适率；**残差 PPO 以最短训练时间取得第二梯队性能**。

### 2.5 计算开销（关键差异点）
| 策略 | 单步决策延迟 | 相对 RL 倍数 | 102 天决策总耗时 |
|---|---:|---:|---:|
| MPC | **57.98 ms** | **×83** | **141.9 s** |
| PPO v6 / v8 | 0.70 / 0.69 ms | ×1 | 1.7 s |
| SAC v3 / v4 | 0.43 ms | ×0.6 | 1.05 s |
| 残差PPO | **0.30 ms** | ×0.43 | **0.73 s** |
| 规则 | 0.004 ms | — | 0.01 s |
| 人工 | 0.001 ms | — | 0.00 s |

- **MPC 的推理成本是 RL 的 83 倍**（102 天总决策 142 s vs 1.7 s）。真实温室控制器（嵌入式/实时）上，
  这意味着 MPC 每秒开销 ~58 ms 会挤占其他任务，且依赖精确模型在线可用。
- **RL 用 ~1 ms 的推理逼近 MPC 的性能**（舒适率差 14.9 pp，但成本低 83 倍）——这是 RL 在本任务的核心价值主张。

## 3. RL 不足定位（基于评估 + 失配分解）

| # | 不足 | 证据 | 根因 |
|---|---|---|---|
| 1 | **精细调节弱** | PPO 白天温湿**双向摆动**（白天冷<20% 19.5% 与 热>28% 7.7% 并存）；MPC 几乎不偏（干<60% 仅 1.9%、冷 10.8%）| RL 只能从奖励信号反推控制律，缺 MPC 的逐步模型前瞻 |
| 2 | **SAC 稳定性差** | SAC v3 最高温 41.9°C、无过热日仅 90.2%、日均温 σ 最大（3.24）| 连续动作在离散投影后"饱和式全开"（顶窗/水泵开满），档位高频抖动 |
| 3 | **奖励塑形收益有限** | `comfort_bonus` 两轮（0.3/0.6）均未提升舒适率（51.8/49.9 ≤ 52.5）| 二值带内奖励与物理可达舒适度错配；且改奖励会扰动产量（v8 果实 8.06 但舒适降 2.6 pp）|
| 4 | **训练成本不低** | PPO 40-50 min、SAC 139 min | 场景覆盖（5 个起始日 × 40 天）与 1536 动作组合的探索需求 |

## 4. 优化方案与训练效果评估

### 4.1 方案一：残差 RL（针对不足 1「精细调节弱」）

**设计**：`动作 = 规则控制器档位 + RL 修正量(±2 档)`，让 RL 只学"修正"，继承基线的调节先验。
实现：`residual_env.py` + `train_residual_ppo.py`。

| 指标 | 规则（基线）| **残差PPO** | 残差 vs 基线 | PPO v6 | MPC |
|---|---:|---:|---:|---:|---:|
| 舒适率 % | 48.8 | **50.9** | **+2.1** | 52.5 | 67.4 |
| 果实 kg/m² | 6.94 | **7.08** | +0.14 | 7.28 | 7.12 |
| 无过热日 % | 100 | 100 | 保持 | 100 | 100 |
| 决策延迟 ms | 0.004 | 0.30 | — | 0.70 | 57.98 |
| **训练耗时 min** | — | **18** | — | 40 | — |

**评估结论**：残差 RL **相对自身基线稳定提升**（舒适 +2.1、果实 +0.14、保持 100% 安全），
**训练耗时仅 18 min（普通 PPO 的 1/2.2）**，是"最经济的可用控制器"；但**未超过普通 PPO v6**。
原因：规则基线本身已含"白天分层调节"先验，RL 可修正空间有限；若以 MPC 为基线理论更优，
但 MPC 单步 58 ms → 60 万步训练需约 10 小时，工程上不可行。

### 4.2 方案二：SAC v4（针对不足 2「SAC 稳定性差」）

**设计**：在 SAC 上叠加 `comfort_bonus 0.3 + smooth_pen 0.1`（惩罚相邻步档位跳变）。
实现：`train_sac_final.py`（新增 `--resume` 支持，因原进程中断而从 300k 续训）。

| 指标 | SAC v3 | **SAC v4** | 变化 | 评价 |
|---|---:|---:|---:|---|
| 无过热日 % | 90.2 | **100.0** | **+9.8** | ✅ 安全性达标 |
| 日内温度 σ | 2.76 | **2.13** | -0.63 | ✅ 更平滑 |
| 最高温 °C | 41.9 | **34.8** | -7.1 | ✅ 极端高温消除 |
| 舒适率 % | 35.9 | 36.4 | +0.5 | ➖ 基本持平 |
| 果实 kg/m² | 6.58 | **5.31** | **-1.27** | ❌ 明显变差 |
| 4月舒适率 % | 52.2 | 33.9 | -18.3 | ❌ 幼苗期变差 |

**评估结论**：`smooth_pen` **成功消除了 SAC 的"饱和式控制"**（最高温 -7.1°C、无过热日 +9.8 pp、日内波动 -0.63），
安全性提升到与 MPC/PPO 同级；但**代价是产量下降 1.27 kg/m²**（关窗抑制了 CO₂ 补充与光合）。
→ **"平滑动作"与"产量"之间存在权衡**，该方案更适合"安全优先"场景。

## 5. 总结论

1. **没有单一最优控制器，只有不同权衡点**：
   - **MPC** = 性能/成功率/稳定性最优，但推理成本 ×83（依赖模型在线可用）；
   - **PPO v6** = RL 综合最优（舒适 52.5、果实 7.28、成本 1/83）；
   - **PPO v8** = 产量最优（8.06）；
   - **残差 PPO** = 最经济（18 min 训练、0.30 ms 推理）；
   - **SAC v4** = 安全最优（100% 无过热）但产量受损；
   - **人工** = 全面垫底（舒适 33.7、果实 3.06、最不稳）；
   - **规则** = 零成本零训练的"及格线"。
2. **RL 的核心价值已被量化**：以**约 1 ms、MPC 的 1/83 推理成本**，达到 MPC **74% 的舒适率**（50.9-52.5 vs 67.4），
   且**完全规避热害**（无过热日 100%）。对真实温室嵌入式控制器，这是可落地的性价比。
3. **奖励塑形的边际收益已耗尽**：两轮 `comfort_bonus` + 一轮 `smooth_pen` 实验表明，
   继续调奖励权重无法突破 52% 舒适率上限——**瓶颈在 RL 的"逐步精细调节"能力，而非奖励设计**。

## 6. 优化方向（下一阶段优先级）

| 优先级 | 方向 | 依据 | 预期 |
|---|---|---|---|
| **P0** | **残差 RL 换用更强基线**（如 MPC 蒸馏/近似 MPC 作为基线）| 残差 RL 证明"基线越强、上限越高"；直接用 MPC 训练太慢 | 有望把舒适率推向 60%+ |
| **P0** | **提升决策频率**（1h → 30min 步长）| MPC 的精细度部分来自步内优化；RL 小时级决策天然粗糙 | 减小白天温湿摆动 |
| **P1** | **动作空间精简**（剔除补光/CO₂ 无效位，1536→384 组合）| 训练期恒 0 的动作位浪费探索 | 样本效率提升 |
| **P1** | **安全性约束 RL**（拉格朗日/CPO）| SAC v4 证明平滑可提安全但伤产量；需显式约束而非惩罚 | 安全与产量解耦 |
| **P2** | **真实温室部署验证** | 全部为仿真结论 | 验证落地性 |

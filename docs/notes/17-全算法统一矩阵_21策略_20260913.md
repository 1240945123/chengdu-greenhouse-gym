**读法**：4-6 月各策略还能拉开差距，**7 月集体崩到 5-25%**。7 月是成都盛夏，
室外极端高温 + 温室"overheat 模式"下仅靠顶窗/湿帘风机难以压住冠层温度——
这是**物理调控能力上限**问题，而非控制算法问题。CrossQ/DAgger 在 4 月很高、6-7 月骤降，
说明它们**用"春季舒适"换取了春季产量**。

## 4. 分组解读

### 4.1 模型预测类（MPC / 前瞻）——舒适率天花板
两者都在 67-68%，`no_overheat_day=100%`、`max_temp≈32°C`。它们显式枚举动作、按一步预测
打分，天然填满舒适窗口。代价是**单次决策慢两个数量级**（~80ms vs RL ~1ms，§5）。

### 4.2 on-policy 离散 RL——"够用"档
TRPO 56.0 / PPO v9 54.8 / PPO v6 52.5 / PPO(600k同协议) 50.1，四者**明显优于人工（33.7%）**，
且延迟 ~1ms。**TRPO 反超 PPO 是同协议下的硬结论**：同为 600k 步、同环境、同超参规模，
TRPO 56.0% vs PPO 50.1%，**+5.9pp**。原因是 TRPO 的 `n_steps=1024` + 信赖域约束在
40 天随机场景下比 PPO 的 2048 步裁剪更稳（PPO 的 `entropy_loss` 从 −7.3 收敛到 −1.7，
策略过早收敛、探索不足）。论文中可将 TRPO 作为"RL 侧代表"与 PPO 并列汇报。

### 4.3 off-policy 连续——两极分化
- **TQC 38.9 / CrossQ 47.4**：能训（TQC 已修好 SAC 的安全短板，最高温 41.9→33.1）。
- **DDPG 14.6 / TD3 14.6 逐位相同**：两者退化到几乎恒定的动作序列（`reward=−1102`）。
  这类算法的确定性策略在网络输出饱和时给出固定动作，等价于"不控制"，因此数值重合——
  是**信号而非常态**：它说明连续动作 + 单步时序差分在该 1536 组合的离散执行器上易塌缩。
- **SAC 35.9 且 maxT 41.9 / 无过热日 90.2%**：唯一仍有"过热日"的策略，是 off-policy 的安全洼地。

### 4.4 P0 / 其他
MaskablePPO（掩码 1536→384）舒适 44.9 但**果实 8.37（次高）**——动作精简带来 Pareto 重排
（详见 `18` P0-1）；多智能体 IPPO 47.0 未超过单体 on-policy；DAgger v1 44.6（蒸馏 MPC 的复合误差代价）。

### 4.5 Pareto 前沿（舒适 × 产量）
非支配点：**前瞻H=1 / MPC（高舒适）** 与 **CrossQ / MaskablePPO / DAgger v1（高产量）** 两组分立。
**产量与舒适率不存在单调关系**：CrossQ 靠"春季高舒适"堆出最高产量，却在夏季失守舒适率。
选型取决于目标函数——这正是论文讨论"目标设定"而非"算法复杂度"的落点。

## 5. 决策延迟（成本-性能前沿）

| 类别 | 代表 | 并发下测得 ms* | 空闲值（待重测） |
|---|---|---:|---:|
| 模型预测 | MPC / 前瞻 H=1 | 82.4 / 86.5 | ~78.2（历史空闲值） |
| on-policy RL | PPO v6 / v9 / PPO600k / TRPO | 1.18 / 1.59 / 1.10 / 1.18 | **待测** |
| off-policy RL | SAC / CrossQ / TQC | 1.65 / 1.23 / 1.45 | **待测** |
| 轻量 | 规则 / PID / Baseline | ~0.002-0.01 | ~0 |

\* **本表延迟在 CPU 并发（PPO 补训 + CrossQ 续训）下测得，绝对值为上界**。核心论点
「**RL 推理成本约为模型预测控制的 1/50~1/80**」的比值方向稳定，但绝对值须在**空闲状态**
用 `measure_latency.py` 重测后定稿（对应审计 `16` §4 P0-2）。

```bash
# 空闲重测（务必在无其它训练时运行）
python -m experiments.controllers.glass_rl.measure_latency --steps 300
# → results/.../rl/algorithm_matrix/latency_idle.json（median / mean / p95）
```

## 6. 对论文的落点

1. **主表**用本表 §2（21 策略 × 舒适/产量/最坏温度），分月表 §3 佐证"7 月失效"。
2. **成本-性能图**（`algorithm_matrix.png` ③）承载核心论点：模型预测精度换延迟，RL 以 ~1/80 成本逼近。
3. **结论句**：在该玻璃温室基准上，**控制性能的瓶颈不在算法复杂度，而在观测信息与目标设定**
   ——矩阵中所有复杂算法（多智能体/掩码/循环/蒸馏）都未超过简单的前瞻搜索与 TRPO
   （证据链见 `18`）。

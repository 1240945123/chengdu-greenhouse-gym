## 1. 论文组成与顺序（严格按序）

**前置部分**：① 封面 → ② 学位论文答辩委员会名单 → ③ 中文题名页 → ④ 英文题名页 →
⑤ 论文独创性及使用授权声明 → ⑥ 其他特别备注（如有）→ ⑦ 目录 → ⑧ 中文摘要 → ⑨ 英文摘要 → ⑩ 符号说明（如有）

**主体部分**：⑪ 论文正文 → ⑫ 参考文献

**附录部分**：⑬ 致谢 → ⑭ 附录（如有）→ ⑮ 作者简历

## 5. 正文（论述）结构与篇幅

### 5.1 三大部分

```
正文 = 绪论（第 1 章） + 论述主体（若干章） + 结论及主要创新点（末章）
```

| 部分 | 要求 |
|---|---|
| **绪论**（第 1 章） | 国内外研究进展回顾与分析 + 立题依据 + 主要研究内容 + 技术路线。**篇幅一般不宜超过论述主体的 1/3** |
| **论述主体** | 自然科学类一般含**材料与方法、结果与分析、讨论、结论及主要创新点**；可**按研究内容分章**，各章须含"材料与方法 / 结果与分析 / 讨论"，章间有逻辑关系、形成有机整体 |
| **结论及主要创新点** | 全文总结与展望；**须严格区分本人成果与导师/他人成果**；创新点要体现"解决什么科学问题 + 在领域中的地位与意义" |

> 另有硬性提醒：**"已经在文献综述部分讲过的内容，不需要再重复"**——即绪论里综述过的，论述主体不要复述。

### 5.2 附录 E 给定的两种章节模式（实验研究类）

**模式一（分块式）**
```
1 绪论      1.1 研究背景及意义 / 1.2 国内外研究现状 / 1.3 主要研究内容 / 1.4 技术路线
2 材料与方法
3 结果与分析
4 讨论
5 结论及主要创新点   5.1 结论 / 5.2 主要创新点
```

**模式二（每章闭环式）**
```
第一章 绪论
第二章 XXXX（据研究内容拟定）  2.1 材料与方法（2.1.1 试验材料 / 2.1.2 试验方法）
                              2.2 结果与分析
                              2.3 讨论
…（可多章同构）
末章 结论及主要创新点
```

## 8. 图表格式

| 项 | 要求 |
|---|---|
| 编号 | 按章两位数字，`图 2-1` 或 `图 2.1`；`表 5-6` 或 `表 5.6` |
| **标题位置** | **表题在表上方；图题在图下方** |
| 中英对照 | **图表标题须有中英文对照，中文在上** |
| 表格样式 | **一律三线表** |
| 表题/图题字体 | 加粗；中文宋体、西文 Times New Roman；五号；居中；无首行缩进；段前后 0；多倍行距 1.25 |
| 表名/图名 | 与序号间空 1 空格；**名称中不用标点、末尾不加标点** |
| 表注/数据来源 | 宋体/Times New Roman 五号，两端对齐，首行缩进 2 字符 |
| 照片 | 反差大、清晰原版；不得用复印图 |
| 附录图表 | 另行编号并冠"附"字，如 `附图1.1`、`附表2-2` |

> ⚠️ **"图表标题须有中英文对照"** — 我们已出的图（第 3 章三张图、算法矩阵图）**都需要补英文标题**。

## 9. 参考文献著录（学校实施细则）

### 9.1 总体

- 依据 **GB/T 7714-2015**；可**顺序编码制**或**著者-出版年制**，**二选一、全文统一**
- **本文选择：顺序编码制**（与已有综述一致）
- 只列"作者阅读过、在正文中被引用或参考过"的文献
- 参考文献表排版：**五号字**，汉字宋体、英文 Times New Roman，**固定行距 20 磅**，段前段后 0
- **同一条文献不跨页**；悬挂缩进，序号悬挂在外；编号左对齐、内容两端对齐；**编号与内容间空 1–3 个半角字符**
- 建议用 **NoteExpress**（学校图书馆可下载）或 EndNote

### 9.2 正文标注（顺序编码制）

| 情形 | 写法 |
|---|---|
| 单篇引用 | 序号置于 `[ ]` **并上标**，如"张三等<sup>[6]</sup>认为" |
| 同处多篇 | `[1, 5, 14-17]`（连续序号用 `-` 连接） |
| 作为句子有效成分 | **不用上标**，如"由文献[8, 10-13]可知" |
| 重复引用 | **始终标注第一次引用的序号** |
| 位置限制 | **除图表标题外，不得将引用标注置于各级章节标题处** |

### 9.3 书写格式（学校表 3-1）

| 类型 | 格式 |
|---|---|
| 期刊论文 | 作者. 文题[J]. 期刊名, 年, 卷(期): 起-止页码. |
| **会议论文** | 作者. 文题[C]. **会议名, 会议地, 会议年: 起-止页码.** ← **不用 `//`** |
| 专著 | 作者. 书名[M]. 译者. 版本. 出版地: 出版者, 出版年: 起-止页码. |
| **学位论文** | 作者. 文题[D]. **授位单位, 授位年: 起-止页码.** ← **不写所在地** |
| 报纸 | 作者. 文题[N]. 报纸名, 出版日期 (版面数). |
| 报告 | 作者. 文题[R]. 出版地: 出版者, 出版年. |
| 专利 | 发明人. 专利名: 专利号[P]. 授权日期. |
| 标准 | 发布单位. 标准名: 标准号[S]. 出版地: 出版者, 出版年: 起-止页码. |
| 电子文献 | 作者. 文题[文献类型/载体标识]. 出版地: 出版者, 出版年: 起-止页码 (更新日期) [引用日期]. 获取路径. DOI. |

### 9.4 著录注意事项（八条）

1. 作者**姓在前、名在后**；英文**姓全拼且首字母大写**、名**大写缩写不加点** → 例：`Harrington R F`、`Vanthoor B H E`
2. 姓名间用逗号；**最多写到第 3 位**，余者用 `, 等` 或 `, et al.`
3. 英文文献**题名仅首词首字母大写**，其余小写；**出处（期刊/会议名）每词首字母大写**，1–4 字母虚词全小写；**期刊名用全称，勿缩写**
4. 标识符号统一**半角**，其后空 1 个半角字符（以中文文献为主时也可全角且不加空格）
5. 日期用 **`YYYY-MM-DD`**
6. 缺某要素则不著录该要素及其标识符号（如无期号：`作者. 文题[J]. 期刊名, 年, 卷: 起-止页码.`）
7. **初版专著不著录版本**；DOI 仅在"获取路径中不含 DOI"时才著录
8. 期刊名用全称

### 11.1 写作约定（为了让导出脚本能自动排版）

| 约定 | 写法 | 作用 |
|---|---|---|
| 表题 | 紧贴表格**上一行**：`**表 2-1 中文名**`<br>下一行：`Table 2-1 English name` | 自动套「五号加粗居中」并拆成中文在上 |

> ⚠️ 只带 `**表 2-1 …**` 而不给表格/图片相邻位置，或表注不写 `注：` 前缀，

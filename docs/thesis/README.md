## 论文在做什么

**脊梁句**：

> 在一个"先被证明可信"的数字孪生体上，强化学习的真实价值不是更高的控制性能（那是模型预测控制类的），
> 而是以约 **1/88** 的推理成本逼近它——并且这一结论，只有在基准自身也做过退化诊断之后才成立。

**三层递进**（章序不可换）：

```
地基层 ─────────────► 比较层 ─────────────► 边界层
第2章 物理孪生          第4章 同协议基准       第5章 提升尝试
第3章 作物标定           21 策略 × 多维         四条提升路线
"这个模型能信吗？"      "信了之后谁强？"       "还能更强吗？"
```

与一般温室 RL 论文的差别：**别人是"跑个 RL 然后说它更好"，本文是"先把裁判校准，再让选手上场"。**

## 一号贡献：可信性诊断三步法

物理孪生不是"修了 4 个 bug"，而是一套**可迁移的诊断方法**：

| 步 | 诊断对象 | 发现 |
|---|---|---|
| ① 逐时通量诊断 | 同一时刻的能量收支逐项核对 | 冠层对流系数低估 19 倍（冠层-空气温差 +39 °C） |
| ② 逐日峰值诊断 | 逐日最高温比对真实传感器，排除瞬态噪声 | `solar_gain_scale` 被清棚异常值误标定（虚假 +20 °C） |
| ③ 单步动作诊断 | 9 个执行器逐一单步激励，看物理响应方向与量级 | 外遮阳透光**语义误用**、保温幕长波阻挡缺失 |

> 三步分别对应 **结构级 / 标定级 / 接口级** 三类失效，且不依赖具体作物与温室型号。

## 主要结论（已在 `docs/notes/17`、`18` 公开）

| 结论 | 数据 |
|---|---|
| MPC / 一步前瞻是性能天花板 | 舒适率 **67.4% / 67.9%** |
| 60 万步预算下 RL 侧最佳是 TRPO | 舒适率 **56.0%**（同协议 PPO 仅 50.1%） |
| RL 的价值是成本 | 空闲实测 **MPC 57.3 ms vs PPO 0.65 ms ≈ 1/88** |
| 基准自身需做退化诊断 | A2C / DQN / DDPG / TD3 等退化为**恒定动作** |
| 7 月高温是共同短板 | 全表 7 月舒适率最高仅 25.0%（配置上限，非技术极限） |
